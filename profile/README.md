# 📦 CSC 3100 Archive

### Software Engineering · Student Projects · Historical Repositories

Welcome to the **CSC 3100 Archive**, a collection of student software engineering projects developed as part of CSC 3100 coursework.

This organization preserves original student implementations, documenting their contributions, design decisions, and development practices.

## 🎓 About This Archive

The repositories represent student work involving software engineering concepts such as:

- Object-oriented design and UML modeling
- Software architecture and design patterns
- Agile development, user stories, and task management
- Version control, branching, and pull requests
- Collaborative software development
- Testing, integration, and documentation

Projects are preserved primarily for **educational and historical reference**.

## 🗂️ Repository Organization

Repository names generally identify the assignment, application, and student team. For example:

`final-project-taigadesktop-emanyutojoseph`

Some projects represent earlier development stages, while others are final submissions. Original implementations and commit histories are preserved whenever possible.

## 🚀 Maintained Applications

Selected student contributions may be reviewed, adapted, and incorporated into maintained applications. Active development takes place in the [CSC 3100 organization](https://github.com/csc-3100).

Examples include:

- [Taiga Desktop](https://github.com/csc-3100/app-taigadesktop) — A desktop application for Taiga project management.
- [CodeViz IntelliJ](https://github.com/csc-3100/app-codeviz-intellij) — Software visualization integrated with IntelliJ IDEA.

Maintained applications may combine ideas from multiple student submissions while preserving attribution to their original authors.

## 🔒 Archive Policy

Repositories in this organization are generally:

- **Read-only:** No further development is expected.
- **Preserved:** Original code and development history are retained.
- **Attributed:** Student contributions remain associated with their original repositories.
- **Educational:** Code may reflect assignment requirements, experimental implementations, or incomplete features.

Archived repositories are not necessarily maintained, tested against current dependencies, or suitable for production use.

## 📚 Acknowledgments

These projects reflect the creativity, effort, and collaboration of CSC 3100 students. Their work provides educational software engineering examples and a foundation for future learning.
